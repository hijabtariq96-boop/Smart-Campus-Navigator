SMART CAMPUS NAVIGATOR - PROJECT FILES

Files:
1. navigator.cpp   C++ backend: campus data + adjacency matrix + Dijkstra + fstream JSON output.
2. index.html      Web page structure.
3. style.css       Page styling.
4. script.js       Leaflet map, search, route UI, GPS, dark map.
5. campus_data.json  Generated by running navigator.cpp.

IMPORTANT: campus_data.json is generated automatically; do not create it manually.

RUN ON WINDOWS (with g++):
  g++ -std=c++17 navigator.cpp -o navigator.exe
  navigator.exe

RUN ON LINUX / Cxxdroid terminal (if g++ is installed):
  g++ -std=c++17 navigator.cpp -o navigator
  ./navigator

Then serve this folder using a local web server (fetch() does not reliably work from file://).
If Python is installed:
  python -m http.server 8000
Open browser: http://localhost:8000

On Android, use a C++ IDE to compile and run navigator.cpp in the same project folder.
Then use an Android local-server app or IDE preview that serves the folder over localhost.
Leaflet/OpenStreetMap tiles need internet. GPS generally needs HTTPS or localhost and permission.

DATA ACCURACY NOTE:
The 24 campus entries and walking-edge distances are carried over from the supplied campus_data.js.
Please verify building names, exact coordinates, ramps, and distances with the university before relying on them for navigation. This is a student prototype, not an official campus map.
